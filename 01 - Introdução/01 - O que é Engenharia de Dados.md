## 2. O que é Engenharia de Dados?

A Engenharia de Dados é o conjunto de técnicas, etapas, processos e procedimentos que permitem transformar dados brutos em dados utilizáveis.

- Os dados são coletados de diferentes fontes.
- Os dados podem ser armazenados temporariamente ou de forma permanente.
- Os dados são processados para torná-los úteis, aplicando técnicas como limpeza e enriquecimento.
- Os dados são organizados e preparados para atender às necessidades dos profissionais que os utilizarão.

Objetivo principal: disponibilizar dados confiáveis, organizados e adequados para análises e outras aplicações.

## 3. Fontes de dados

O engenheiro de dados precisa identificar e estabelecer conexões com uma ou mais fontes de dados.

Exemplos de fontes:

- Bancos de dados relacionais: dados organizados em tabelas e relacionamentos.
- Bancos de dados não relacionais: dados armazenados em estruturas alternativas às tradicionais tabelas relacionais.
- Ambientes em nuvem: serviços e plataformas que armazenam ou disponibilizam dados.
- Páginas web: informações obtidas de sites e aplicações web.
- Planilhas Excel: dados tabulares armazenados em arquivos.
- Arquivos PDF: documentos que podem conter informações textuais e estruturadas.
- Imagens e vídeos: dados que podem ser utilizados em diferentes tipos de análise.

Quando necessário, o engenheiro de dados precisa integrar informações provenientes de várias fontes simultaneamente. 

## 4. Etapas e processos da Engenharia de Dados

O trabalho do engenheiro de dados envolve diferentes etapas para transformar dados brutos em informações prontas para uso.

- Conexão com as fontes: estabelecer acesso aos sistemas e arquivos que contêm os dados.
- Extração: coletar os dados das fontes identificadas.
- Armazenamento: guardar os dados em locais apropriados, temporários ou permanentes.
- Processamento: preparar os dados para sua utilização.
  - Limpeza de dados.
  - Enriquecimento de dados.
  - Transformação e organização das informações.
- Catalogação: registrar e organizar informações sobre os dados disponíveis.
- Qualidade dos dados: verificar se os dados atendem aos requisitos necessários para seu uso.
- Linhagem dos dados: acompanhar a origem dos dados e as transformações pelas quais passaram.
- Disponibilização: entregar os dados em um formato adequado para análise e outras aplicações.

### Tecnologias e conceitos de armazenamento

- Data Warehouse (DW): ambiente de armazenamento voltado principalmente à análise de dados estruturados e integrados.
- Data Lake: repositório que permite armazenar grandes volumes de dados em diferentes formatos.
- Data Lakehouse: abordagem que combina características dos Data Lakes e dos Data Warehouses.

A escolha da solução depende das características dos dados e das necessidades do projeto.

## 5. Relação entre Engenharia de Dados e Ciência de Dados

O crescimento da Ciência de Dados aumentou a demanda por profissionais capazes de desenvolver modelos de Machine Learning e realizar previsões.

Entretanto, as empresas perceberam que, antes de analisar os dados, era necessário resolver questões fundamentais:

- De onde vêm os dados?
- Como coletar dados de diferentes fontes?
- Como organizar e gerenciar os dados?
- Como garantir a qualidade dos dados?
- Como disponibilizar os dados para os cientistas de dados?

Essas necessidades evidenciaram a importância da Engenharia de Dados.

### Responsabilidades dos cientistas de dados

- Aplicar matemática e estatística.
- Desenvolver modelos de Machine Learning.
- Realizar análises e identificar padrões.
- Construir modelos preditivos.
- Extrair conhecimento e gerar valor a partir dos dados.

### Responsabilidades dos engenheiros de dados

- Construir processos de coleta e movimentação de dados.
- Integrar diferentes fontes de dados.
- Implementar soluções de armazenamento e processamento.
- Preparar e disponibilizar dados para análise.
- Cuidar da qualidade, organização e linhagem dos dados.

Ponto importante: embora exista colaboração entre essas áreas, cada uma possui responsabilidades específicas. O engenheiro de dados cria a infraestrutura e os processos que permitem aos demais profissionais trabalhar com dados adequados às suas necessidades.

## 6. Importância do engenheiro de dados no mercado

A Engenharia de Dados tornou-se cada vez mais relevante devido à necessidade de preparar e movimentar grandes volumes de dados para diferentes aplicações.

- O crescimento da Ciência de Dados evidenciou a necessidade de profissionais especializados na gestão e preparação dos dados.
- O engenheiro de dados conecta as fontes de informação aos profissionais e sistemas que utilizarão esses dados.
- Sua atuação permite que cientistas de dados se concentrem mais em análises, experimentos e modelos de Machine Learning.
- A profissão vem ganhando destaque no mercado de tecnologia e de dados.

Segundo o instrutor, no contexto das formações da DSA, a formação de Cientista de Dados era a mais procurada pelos alunos, seguida pela formação de Engenheiro de Dados.

## 7. Resumo geral

- Engenharia de Dados: transforma dados brutos em dados utilizáveis.
- Fontes de dados: podem incluir bancos de dados, arquivos, páginas web e serviços em nuvem.
- Processamento: envolve extração, armazenamento, limpeza, enriquecimento, catalogação e controle de qualidade.
- Armazenamento: pode utilizar Data Warehouses, Data Lakes e Data Lakehouses.
- Disponibilização: os dados são preparados para atender às necessidades de analistas, cientistas de dados, engenheiros de Inteligência Artificial e outros profissionais.
- Importância profissional: o engenheiro de dados viabiliza o uso eficiente dos dados, criando a base necessária para análises e soluções inteligentes.

Ideia central: a Engenharia de Dados é responsável por construir os processos que levam os dados desde suas fontes originais até um formato confiável e utilizável, permitindo que outros profissionais extraiam valor dessas informações.
