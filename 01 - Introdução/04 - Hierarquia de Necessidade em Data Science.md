# Engenharia de Dados — Hierarquia de Necessidades em Data Science

## 1. O que é a Hierarquia de Necessidades em Data Science?

- É uma pirâmide conceitual criada em 2017, que representa as etapas necessárias para desenvolver soluções baseadas em dados.
- A pirâmide demonstra que análises avançadas, Machine Learning e Inteligência Artificial dependem de uma base sólida de dados e infraestrutura.
- Sua ideia central é que não é possível construir soluções analíticas confiáveis sem antes garantir a disponibilidade e a qualidade dos dados.
- A referência do autor e da pirâmide original foi indicada pelo instrutor na seção de links úteis do capítulo.

Esquema didático das camadas descritas na aula, organizado de baixo para cima.

### Camada 1 — Geração e coleta de dados

É a base da pirâmide, onde os dados são gerados ou obtidos.

- Logs de sistemas e aplicações.
- Dados de sensores.
- Dados provenientes de fontes externas.
- Conteúdo gerado por usuários.

Objetivo: obter a matéria-prima necessária para as etapas seguintes.

### Camada 2 — Infraestrutura e pipelines de dados

Nesta camada, os dados passam a ser coletados, movimentados, armazenados e disponibilizados de forma estruturada.

- Construção de pipelines de dados.
- Implementação da infraestrutura necessária.
- Armazenamento de dados estruturados e não estruturados.
- Garantia de confiabilidade e disponibilidade dos dados.

Objetivo: criar uma base técnica que permita processar e disponibilizar os dados de maneira consistente.

### Camada 3 — Preparação dos dados

Os dados são tratados para que possam ser utilizados nas análises.

- Limpeza de dados.
- Detecção de anomalias.
- Preparação e transformação dos dados.
- Tratamento de problemas que possam prejudicar os resultados.

Objetivo: tornar os dados adequados para análises e aplicações posteriores.

### Camada 4 — Analytics

Nesta etapa, os dados preparados são utilizados para gerar informações analíticas.

- Construção e acompanhamento de métricas.
- Segmentação de dados.
- Agregação de informações.
- Preparação de dados para análises e relatórios.

Objetivo: transformar os dados em informações úteis para compreender o negócio e apoiar decisões.

### Camada 5 — Machine Learning e experimentos

Nesta camada, os dados são utilizados em experimentos e modelos de aprendizado de máquina.

- Testes A/B.
- Experimentação.
- Desenvolvimento e avaliação de algoritmos de Machine Learning.

Objetivo: testar hipóteses, identificar padrões e desenvolver modelos capazes de produzir previsões ou classificações.

### Camada 6 — Inteligência Artificial e Deep Learning

Representa o topo da pirâmide, com aplicações mais avançadas de Inteligência Artificial.

- Desenvolvimento de soluções de IA.
- Aplicações de Deep Learning.
- Construção de sistemas inteligentes e automatizados.

Objetivo: utilizar os dados e os modelos desenvolvidos para resolver problemas complexos e criar aplicações avançadas.

## 3. Relação entre Engenharia de Dados e Ciência de Dados

A pirâmide evidencia a dependência entre a base técnica e as aplicações analíticas.

- Engenharia de Dados: concentra-se principalmente na coleta, infraestrutura, pipelines, armazenamento, processamento e preparação dos dados.
- Analytics: utiliza os dados para gerar métricas, indicadores e informações úteis.
- Machine Learning e IA: utilizam dados para desenvolver modelos e soluções avançadas.

Essas áreas não são completamente isoladas. Na prática, suas responsabilidades podem se sobrepor, dependendo da organização e do projeto.

O ponto principal é que as camadas superiores dependem do trabalho realizado nas inferiores.

## 4. A analogia com uma indústria têxtil

O instrutor compara a Engenharia de Dados a uma linha de produção industrial.

Imagine a fabricação de uma camisa:

- Matéria-prima: algodão obtido na plantação.
- Processamento inicial: transformação do algodão em matéria adequada à fabricação.
- Produção: utilização dos materiais para confeccionar a camisa.
- Produto final: camisa pronta para ser utilizada.

Na Engenharia de Dados, a lógica é semelhante:

- Matéria-prima: dados brutos.
- Processamento: coleta, limpeza, transformação e organização.
- Preparação para uso: disponibilização de dados confiáveis.
- Aplicação final: análises, modelos de Machine Learning e soluções de Inteligência Artificial.

Assim como não é possível fabricar uma camisa sem os materiais e processos necessários, não é possível construir soluções analíticas confiáveis sem uma base adequada de dados.

## 5. Por que a base da pirâmide é tão importante?

As camadas superiores costumam receber mais atenção porque envolvem aplicações sofisticadas, como IA, Deep Learning e Machine Learning.

Entretanto, essas soluções dependem de uma infraestrutura confiável.

- Dados insuficientes podem limitar o desenvolvimento dos modelos.
- Dados de baixa qualidade podem prejudicar as análises e previsões.
- Pipelines inadequados podem comprometer a atualização e a disponibilidade dos dados.
- Falhas de armazenamento e processamento podem dificultar a execução dos projetos.

Por isso, a Engenharia de Dados é fundamental para viabilizar as demais etapas.

Importante: embora a base seja indispensável, todas as camadas possuem valor. A pirâmide representa dependências entre etapas, não que a Engenharia de Dados seja a única área importante.

## 6. Engenharia de Dados para outras carreiras

Aprender os fundamentos de Engenharia de Dados também é útil para profissionais que pretendem seguir outras áreas do universo dos dados.

- Analistas de Dados: compreendem melhor a origem, a preparação e as limitações dos dados utilizados nos relatórios.
- Cientistas de Dados: entendem como a qualidade e a disponibilidade dos dados afetam os modelos.
- Arquitetos de Dados: compreendem os requisitos técnicos envolvidos na construção de ambientes de dados.
- Engenheiros de Machine Learning: entendem melhor os fluxos de dados necessários para treinar e disponibilizar modelos.
- Engenheiros de IA: compreendem a importância dos dados e dos pipelines que alimentam as soluções inteligentes.

Conhecer esses fundamentos permite utilizar os dados de maneira mais eficiente, independentemente da especialização escolhida.
