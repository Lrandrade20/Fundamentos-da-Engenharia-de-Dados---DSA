# Engenharia de Dados — Importância na Ciência de Dados

## 1. A importância dos dados para as empresas

- Os dados são considerados ativos corporativos, pois permitem que as empresas extraiam valor das informações que possuem.
- Quando bem utilizados, os dados ajudam as organizações a:
  - Melhorar estratégias corporativas.
  - Identificar padrões e tendências.
  - Realizar previsões.
  - Detectar problemas e anomalias.
  - Agir preventivamente diante de possíveis riscos.
  - Tomar decisões mais eficientes.

\- Para aproveitar esses benefícios, não basta possuir dados: é necessário coletá-los, organizá-los, armazená-los e garantir sua qualidade.

Conceito-chave: os dados são a matéria-prima para a geração de informações e conhecimentos que auxiliam na tomada de decisões.

## 2. O papel da Engenharia de Dados na Ciência de Dados

A Engenharia de Dados fornece a infraestrutura e os processos necessários para que os dados possam ser utilizados em projetos de Ciência de Dados.

Principais responsabilidades:

- Coletar dados de diferentes fontes.
- Armazenar e organizar os dados.
- Processar e transformar os dados brutos.
- Garantir a qualidade e a confiabilidade dos dados.
- Disponibilizar dados adequados para análises e modelos de Machine Learning.

A Engenharia de Dados é fundamental porque os resultados de um projeto de Ciência de Dados dependem diretamente da qualidade dos dados utilizados.

Relação fundamental:

- Engenharia de Dados prepara e disponibiliza os dados.
- Ciência de Dados utiliza os dados para realizar análises, identificar padrões e desenvolver modelos.
- A empresa utiliza os resultados para tomar decisões e gerar valor.

## 3. Cultura orientada a dados (Data-Driven)

Uma cultura Data-Driven, ou cultura orientada a dados, é aquela em que as decisões são tomadas com base em dados, evidências e análises, em vez de depender exclusivamente de opiniões ou suposições.

### Tomada de decisão baseada em achismos

- Depende principalmente da experiência e da percepção das pessoas.
- Pode levar a decisões equivocadas.
- Não necessariamente considera padrões históricos ou evidências concretas.
- Pode funcionar em algumas situações, mas apresenta limitações quando utilizada como principal método de decisão.

### Tomada de decisão baseada em dados

- Utiliza informações concretas para fundamentar decisões.
- Permite identificar padrões em dados históricos.
- Ajuda a realizar previsões com base em evidências.
- Facilita a identificação de anomalias e tendências.
- Possibilita decisões mais consistentes e fundamentadas.

O uso de dados não elimina a necessidade de experiência e julgamento humano, mas oferece evidências para melhorar as decisões.

## 4. A relação entre qualidade dos dados e cultura Data-Driven

A confiabilidade dos dados é essencial para estabelecer e manter uma cultura orientada a dados.

- Dados de qualidade: contribuem para análises consistentes, relatórios confiáveis e previsões mais úteis.
- Dados de baixa qualidade: podem gerar divergências nos relatórios, análises incorretas e previsões pouco confiáveis.

Quando os usuários percebem que os dados não são confiáveis, podem perder a confiança nas análises e deixar de utilizá-las para tomar decisões.

Por isso, a qualidade dos dados precisa ser tratada como uma prioridade contínua.

### Consequências dos problemas de qualidade

- Relatórios com informações incorretas.
- Resultados divergentes entre diferentes análises.
- Modelos de Machine Learning com desempenho inadequado.
- Previsões que não correspondem à realidade.
- Perda de confiança dos usuários nas informações.
- Enfraquecimento da cultura orientada a dados.

Ponto importante: construir uma cultura Data-Driven exige tempo, processos confiáveis e comprometimento organizacional. Problemas recorrentes de qualidade podem comprometer essa cultura.

## 5. Por que a Engenharia de Dados deve vir antes do Machine Learning?

Algumas empresas começam seus projetos investindo diretamente em Machine Learning, buscando desenvolver modelos sofisticados e realizar previsões.

Entretanto, esses projetos podem falhar quando não existe uma base adequada de Engenharia de Dados.

Problemas comuns:

- Volume insuficiente de dados.
- Dados com qualidade inadequada.
- Ausência de processos eficientes de coleta.
- Falta de uma estratégia de armazenamento.
- Dificuldade para manter os fluxos de dados.
- Falta de confiabilidade nas informações utilizadas pelos modelos.

O problema não está necessariamente na Ciência de Dados ou no Machine Learning, mas na ausência de uma matéria-prima adequada para o trabalho.

### Sequência lógica para projetos de dados

1\. Engenharia de Dados

Coleta, armazenamento, processamento e qualidade

2\. Ciência de Dados

Análises, identificação de padrões e desenvolvimento de modelos

3\. Resultados e decisões

Previsões, insights e geração de valor para o negócio

Essa sequência representa uma dependência importante: os projetos analíticos precisam de dados adequados. Na prática, as etapas podem ocorrer de forma iterativa, com melhorias contínuas ao longo do projeto.

## 6. Conceitos fundamentais para memorizar

- Ativo corporativo: recurso que pode gerar valor para a empresa; os dados são um exemplo.
- Data-Driven: abordagem de gestão em que decisões são fundamentadas em dados e evidências.
- Qualidade dos dados: grau em que os dados atendem aos requisitos de utilização, considerando aspectos como precisão, completude e consistência.
- Engenharia de Dados: área responsável por construir os processos que tornam os dados disponíveis e utilizáveis.
- Ciência de Dados: área que utiliza técnicas analíticas, estatísticas e computacionais para extrair conhecimento dos dados.
- Machine Learning: conjunto de técnicas que permite desenvolver modelos capazes de identificar padrões e produzir previsões ou classificações a partir de dados.

## 7. Resumo final

A Engenharia de Dados é uma das bases para o sucesso da Ciência de Dados porque fornece a matéria-prima necessária para análises e modelos: dados disponíveis, confiáveis e adequados ao uso.

Sem processos sólidos de coleta, armazenamento, processamento e controle de qualidade, uma empresa pode enfrentar dificuldades para implementar Machine Learning e manter uma cultura orientada a dados.

A ideia central da aula é que não basta investir em modelos sofisticados; é preciso garantir que os dados utilizados sejam confiáveis. A Engenharia de Dados estabelece essa base e contribui para que os dados realmente gerem valor para o negócio.
