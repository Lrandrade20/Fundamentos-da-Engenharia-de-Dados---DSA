# Engenharia de Dados — Definições formais e áreas de atuação

## 1. Definição de Engenharia de Dados

A Engenharia de Dados é o conjunto de técnicas, processos e procedimentos utilizados para transformar dados brutos em dados disponíveis, acessíveis e prontos para uso.

Principais objetivos:

- Tornar os dados brutos utilizáveis para cientistas de dados e outros profissionais da organização.
- Facilitar o acesso aos dados pelos seus consumidores.
- Garantir que os dados estejam preparados para análises e tomadas de decisão.
- Coletar, processar, validar, organizar e disponibilizar dados em formatos adequados.

Conceito fundamental: raramente os dados estarão prontos para uso diretamente na fonte. Na maioria dos casos, é necessário aplicar processos de transformação e preparação antes de disponibilizá-los.

## 2. Quem são os clientes do engenheiro de dados?

O engenheiro de dados entrega os resultados do seu trabalho a outros profissionais que precisam utilizar os dados. Esses profissionais são seus consumidores de dados.

Principais consumidores:

- Cientistas de dados: utilizam os dados para desenvolver modelos de Machine Learning, realizar análises e construir previsões.
- Analistas de dados: utilizam os dados para investigar informações, identificar tendências e gerar relatórios.
- Gestores e diretores: analisam informações para tomar decisões estratégicas.
- Tomadores de decisão: utilizam dados para orientar ações e processos da organização.
- Outros profissionais: qualquer pessoa ou equipe que necessite de dados para executar suas atividades.

O cientista de dados costuma ser um dos principais clientes do engenheiro de dados, mas não é o único.

## 3. Exemplos práticos de utilização

A Engenharia de Dados não precisa necessariamente atender a projetos de Ciência de Dados ou Machine Learning.

Dependendo das necessidades da empresa, o trabalho pode ser mais simples.

Exemplo: alimentação de dashboards

- O engenheiro de dados coleta informações de uma ou mais fontes.
- Processa e organiza os dados.
- Disponibiliza os dados em formato tabular, como planilhas Excel ou arquivos CSV.
- Os dados alimentam um dashboard no Power BI.
- Gestores, diretores e outros profissionais utilizam o dashboard para analisar informações e tomar decisões.

Nesse cenário, pode não haver necessidade de um cientista de dados. O objetivo principal é disponibilizar dados organizados para relatórios e visualizações.

## 4. Qualidade e validação dos dados

Os dados coletados nem sempre apresentam qualidade adequada para uso imediato.

Problemas comuns:

- Dados faltantes: informações que deveriam estar preenchidas, mas estão ausentes.
- Dados incorretos: valores registrados de maneira errada.
- Dados inconsistentes: informações conflitantes entre registros ou fontes.
- Dados incompletos: registros que não possuem todas as informações necessárias.
- Problemas de integridade: dados que não respeitam as regras e relações esperadas.

O engenheiro de dados pode ser responsável por processos de validação e preparação para assegurar que os dados estejam adequados às necessidades dos consumidores.

Essa atividade está relacionada à qualidade dos dados, tema que exige técnicas e procedimentos específicos.

## 5. Modelagem de dados

A modelagem de dados é uma parte importante da Engenharia de Dados.

- Define como os dados serão organizados e relacionados.
- Ajuda a estruturar os dados de acordo com as necessidades de utilização.
- Facilita a consulta, a análise e a interpretação das informações.
- Contribui para a organização e a qualidade dos dados.

A modelagem está relacionada tanto à preparação dos dados quanto ao planejamento de como eles serão armazenados e utilizados.

## 6. Principais áreas da Engenharia de Dados

A Engenharia de Dados é um campo amplo, composto por diferentes áreas de conhecimento.

- Infraestrutura de dados: recursos e ambientes necessários para armazenar, processar e disponibilizar dados.
- Aquisição de dados: coleta de dados provenientes de diferentes fontes.
- Mineração de dados: exploração de conjuntos de dados para identificar padrões e informações relevantes.
- Processamento de dados: execução de operações de limpeza, transformação e preparação.
- Modelagem de dados: definição da estrutura e dos relacionamentos entre os dados.
- Gerenciamento de dados: organização, controle, manutenção e administração dos dados.

Essas áreas se complementam para permitir que os dados sejam utilizados de maneira eficiente.

## 7. Evolução dos perfis profissionais da área de dados

Com o crescimento da utilização de dados nas empresas, as responsabilidades profissionais passaram a ser distribuídas entre diferentes especializações.

### 1. Cientista de Dados

- Ganhou destaque com a expansão da Ciência de Dados.
- Atua em análises avançadas, estatística, Machine Learning e previsões.

### 2. Engenheiro de Dados

- Ganhou importância diante da necessidade de coletar, preparar e movimentar grandes volumes de dados.
- Atua principalmente na implementação técnica dos processos e das soluções de dados.

### 3. Arquiteto de Dados

- Assume responsabilidades relacionadas ao planejamento e à arquitetura dos ambientes de dados.
- Ajuda a definir como os dados serão estruturados, integrados, armazenados e gerenciados.

Essa divisão acontece porque o volume e a complexidade do trabalho aumentam à medida que as empresas utilizam dados em mais processos.

### Outros perfis profissionais mencionados

- Engenheiro de Machine Learning: trabalha na implementação e operacionalização de soluções de aprendizado de máquina.
- Engenheiro de DataOps: atua na automação, integração e melhoria dos processos e fluxos de trabalho relacionados aos dados.
- Engenheiro de IA: trabalha na implementação de sistemas e soluções de Inteligência Artificial.

As responsabilidades desses profissionais podem se sobrepor, dependendo da estrutura e das necessidades de cada organização.

## 9. Resumo para revisão

- Engenharia de Dados: conjunto de técnicas e procedimentos para tornar os dados disponíveis em formatos utilizáveis.
- Principal objetivo: transformar dados brutos em dados preparados para atender às necessidades dos consumidores.
- Consumidores de dados: cientistas, analistas, gestores, diretores e outros profissionais.
- Qualidade dos dados: envolve identificar e tratar problemas como dados faltantes, incorretos e inconsistentes.
- Modelagem de dados: organiza os dados e seus relacionamentos para facilitar sua utilização.
- Áreas de conhecimento: infraestrutura, aquisição, mineração, processamento, modelagem e gerenciamento de dados.
- Evolução profissional: o crescimento da demanda por dados favoreceu a especialização e a divisão de responsabilidades entre diferentes perfis.

Ideia central: o engenheiro de dados transforma a disponibilidade dos dados em algo prático para a organização, implementando os processos técnicos que permitem que outros profissionais utilizem informações confiáveis e adequadas às suas necessidades.
